Welcome to Cipherdrop

Your secure message storage solution.

What is Cipherdrop?

Cipherdrop is a platform to safely store password encrypted burner Messages

Privacy & Security

Your Burnermessages are encrypted in the frontend on your device, so the server itself has zero knowledge of your message or password.
The online thing stored on the server is your encrypted message and an encrypted control message.
Every Message is deleted after it's set time to life or the maximum of openings is reached.

Technologies

This project uses the following technologies:

  • Frontend: HTML, CSS, JavaScript
  • Backend: Node.js, Express.js
  • Storage: Redis
  • Encryption: Crypto.js
